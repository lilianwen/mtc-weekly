MTC 技术动态周报 (2026-08-10 ~ 2026-08-17)

各仓库近期更新总结

google/trillian

本周该仓库是唯一有活跃更新的项目，主要围绕一个潜在的安全/稳定性漏洞进行修复。

核心更新： - 安全漏洞修复：发现并修复了在 PREORDERED_LOG 类型树中，GetLeavesByRange RPC 方法的 Count 参数未做边界检查的问题。攻击者可能通过传入一个极大的 Count 值导致服务崩溃，构成拒绝服务（DoS）风险。相关 Issue (#3914) 和 PR (#3915) 均指向此问题，表明团队正在积极处理这一安全隐患。

其他变动： - 一项提议将依赖项从 bitbucket.org/creachadair/shell 迁移至 GitHub 上的 creachadair/mds (#3916)。这属于依赖库的维护性更新，对核心协议或功能无直接影响。

其他仓库

google/merkle-tree-certificate、cloudflare/merkle-tree-certificate 以及 IETF 相关工作组的草案仓库 ietf-wg-acme/draft-ietf-acme-mtlscert 在过去一周均无公开提交或合并。

重点关注清单

  1. Trillian 中的潜在 DoS 风险：关注 PREORDERED_LOG 树类型的 GetLeavesByRange 接口修复进展，这关系到日志服务的稳定性与抗攻击能力。
  2. MTC 核心实现库的静默期：Google 和 Cloudflare 的核心 MTC 实现仓库近期无变更，可能意味着实现已趋于稳定，或主要开发活动转移至其他分支或内部仓库。
  3. IETF 标准草案的推进状态：ACME 扩展草案仓库无更新，建议关注 IETF 会议或邮件列表以获取标准制定进程的最新动态。
